# 🎬 AI 기반 영화 줄거리 요약 & 추천 프로젝트

## 📌 프로젝트 개요
TMDB API를 활용하여 영화 데이터를 수집하고  
WordCloud 분석, TOP10 시각화, AI 요약 및 추천 기능을 구현한 프로젝트입니다.

## 🔍 기능
- TMDB API 영화 데이터 수집
- 인기 영화 Top10 그래프 시각화
- WordCloud 텍스트 분석
- 영화 줄거리 요약 기능
- 장르 기반 영화 추천

## 🛠 기술 스택
Python / Pandas / Matplotlib / WordCloud / TMDB API / NLTK

## 📁 파일 구성
| 파일 | 설명 |
|---|---|
| Project.ipynb | 분석/시각화/요약/추천 메인 코드 |
| project.py | 실행 코드 또는 보조 코드 |
