# 🎬 AI 기반 영화 줄거리 요약 & 추천 시스템 프로젝트

본 프로젝트는 **TMDB API (The Movie Database)**를 활용하여  
최신 영화 데이터를 수집하고, 텍스트 분석 및 AI 요약 기능을 적용하여  
**줄거리 요약·인기 Top10 시각화·장르 기반 추천을 수행하는 데이터 분석 프로젝트**입니다.  
(학교 데이터 분석 프로젝트 과제 제출용)

---

## 📁 1. 프로젝트 개요

OTT 환경에서 영화 콘텐츠는 방대하지만  
사용자는 줄거리·평점·장르 정보를 빠르게 파악하기 어렵다는 문제점이 있습니다.

👉 이를 해결하기 위해  
📌 **줄거리 요약 + 시각화 + 추천 기능을 한 번에 확인할 수 있는 분석 시스템**을 개발했습니다.

### 수행 목표
- TMDB API를 활용한 영화 데이터 수집 자동화
- 텍스트 기반 줄거리 요약 모델 구현
- WordCloud로 핵심 단어 시각화
- 인기 영화 Top10 순위 시각화
- 장르 기반 영화 추천 기능 구현

---

## 🔎 2. 데이터 수집 (TMDB API)

📌 사용 API : **TMDB (https://www.themoviedb.org/)**  
📌 요청 방식 : `requests.get()` → JSON 형태 응답 → Pandas DataFrame 변환

수집 데이터 컬럼 예시

| 컬럼명 | 설명 |
|---|---|
| title | 영화 제목 |
| overview | 줄거리 요약 텍스트 |
| vote_average | 평균 평점 |
| popularity | 인기 지수 |
| release_date | 개봉일 |
| genre_ids | 장르 코드 |

---

## 🧹 3. 데이터 전처리 과정

📌 수집된 데이터에 대해 아래 전처리 수행:

### ✔ 텍스트 정제
- 특수문자 제거
- 공백 정리
- 소문자 변환

### ✔ 분석용 정리
- `release_date` → datetime 형식 변환
- `vote_average, popularity` → numeric 타입 변환
- `overview` → 형태소 분석(Okt) + 불용어 제거
- TF-IDF 기반 벡터화 (추천 모델용)

### ✔ 목적
- 가독성 향상 및 요약 모델 적용 가능하게 정제
- 추천 정확도 향상
- 시각화 분석이 가능한 데이터 상태 확보
